# T07 검증 결과

- 검사 시각: 2026-09-15T02:12:32.252Z
- 환경: Node.js 24.19.0, 빌드된 Cloudflare Worker, Miniflare 임시 로컬 D1
- 인증 HTTP: 60개 통과
- 관찰·세션 만료 HTTP: 23개 통과
- 집계: 삭제 제외, 중복된 막힘 항목, 서울 날짜 경계, 시간 차이, 빈 집계 검사 통과
- 동시 일일 저장: 200 한 건과 409 한 건, 실제 저장 한 건
- 종료 후 임시 계정 및 로컬 D1 제거. 운영 DB에는 테스트 기록을 만들지 않음.

## 확인한 범위

비로그인 화면 이동 및 API 거절, 양방향 타인 자료 읽기·수정·삭제 거절, 소유자 위조 무시, 잘못된 비밀번호와 없는 계정의 동일한 응답, salt가 다른 bcrypt 해시, 세션 폐기·만료, 비밀번호 변경, 자기 자료 내보내기, 계정 삭제, 관찰 순서와 변경 전후 집계.

## 한계

실제 5일 사용 기록이 아니다. 합성 날짜는 로컬 관찰 검사를 위한 값이다. 운영 환경의 기존 소유자 계정 연결과 실제 브라우저 화면·로그인 클릭은 이번 검사에 포함하지 않았다. 로컬 HTTP 검증이 모든 보안 공격을 검사한 것은 아니다.
